# Gap Analysis Anclora Linguo Cam

Fecha: 2026-07-24

## Hallazgos

- La interfaz usaba una paleta ad hoc basada en negro, blanco, zinc y azul.
- La marca visible alternaba entre `Anclora LinguoCAM`, `LinguoCam` y el nombre con espacio.
- El icono principal era un globo genérico en bloque azul, no una marca Anclora.
- El favicon no seguía el sistema de iconos interno.
- El panel de cookies tenía botón flotante y categorías opcionales no respaldadas por scripts reales.
- El footer existía, pero no quedaba como elemento normal del flujo visual en todas las pantallas.
- Las páginas legales tenían texto y enlaces con estilos hardcodeados.

## Criterio aplicado

La tarea establece `Anclora Linguo Cam` como producto interno. La Bóveda aún mantiene
referencias históricas que lo clasifican como producto independiente o parcial. Para esta
intervención se toma el prompt como fuente operativa y se documenta el conflicto.

Anclora Linguo Cam aún no tiene tokens propios en el contrato canónico de color. Para evitar
inventar una paleta, se aplica temporalmente la familia interna teal ya contratada en la Bóveda.
El logo se mantiene como placeholder basado en la geometría de icono interna.

## Resultado Esperado

- Nombre visible unificado como `Anclora Linguo Cam`.
- Tema claro y oscuro basado en tokens CSS.
- Footer operativo con reapertura de cookies desde el propio pie.
- Banner de cookies sin botón flotante y sin categorías falsas.
- Favicon y marca placeholder alineados con el sistema Anclora.
